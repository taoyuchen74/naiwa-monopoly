新构建使用esbuild合并及移除未使用代码，输出1个761,531字节脚本，gzip为215,735字节；保留许可证说明。fontTools将原字体按运行时支持字符生成937字码的WOFF2子集，93,208字节，改名Naiwa Game UI，保留原始字体和OFL许可。字体摘要与字码清单随源代码保存，测试独立核对当前界面所需字符均在子集中。

上述为文件正文体积与本次生成结果，浏览器实际传输量还受服务器压缩和缓存影响。没有用本地预览的时间与远程站时间作加载提速百分比比较。

单文件重新内嵌WOFF2，体积由2.72 MB降至约0.91 MB；通过file://打开，6个角色正常、字体加载成功、外部HTTP请求为0。

## 发布与缓存

开发源码保留在dist/，npm run build生成单文件与out/优化目录；npm run build:site仅生成out/。out/包含一个脚本、样式、子集字体、短笑声、图标、许可证、首页、服务工作线程和构建信息。资源以内容摘要命名，不再依赖手动版本号更新每个模块。

首页配置本版的音频地址与服务工作线程地址；服务工作线程对资源使用缓存优先，对导航尝试网络并可回退至已完整缓存的首页。检测到不同构建的新首页时，不将它写入旧版完整离线缓存，防止更新中断破坏上一版离线入口。缓存前缀带项目路径，清理旧版本时不清除同域其他项目。
