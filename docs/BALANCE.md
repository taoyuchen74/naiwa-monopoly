# 策略与平衡：2026-10-23

目标是让用卡、路线、街区建设和资金保留改变对局结果；不把“模拟全部跑完”视为真人平衡已经得到证明。

## 本版实际规则

| 项目 | 数值及取舍 |
|---|---|
| 起始资源 | 3,200 奶币、60 点券，角色同规则 |
| 点券 | 上限 150；行动结束 +12，过起点 +25，到补给站 +30；不计净资产 |
| 用卡及购卡 | 自己掷骰前 1 张；每回合最多买 2 张，卡包 8 张 |
| 工程队 | 65 点券免费加一层，限附近自己的未满级房屋，不占常规建设次数 |
| 拆层及抢地 | 拆一层 25 点券；抢地 45 点券并补偿业主 125% 成本，均限道路距离 8 格 |
| 其他卡 | 控骰 30、路障 20、回头 20、免租 35、恢复 20、三次慢行 25 点券 |
| 常规建设 | 每回合一次；当地约 75 折，价格按 10 奶币取整 |
| 基础租金 | 地价乘 0.16／0.42／0.85／1.4，对应空地和 1—3 级，四舍五入 |
| 街区联营 | 加收自己同街区其他房产基础租金的 35%，合计最多为当前地产基础租金 2 倍 |
| 银行 | 存款每轮 0.5% 向下取整，贷款每轮 4% 计入本金；借款额度 1,800 |
| 开局与轮数 | 新局随机先手，每名存活玩家每轮行动一次；旧局保留原先手 |

## 如何影响局势

- 控骰和换骰子数量前可查看概率与当前付租风险；岔路按最终落点比较，不能只看紧邻一格。预览不读取未来随机结果、不改变种子。
- 远程常规建设限一次，可保留机会争取在落到自家地时打折。工程队、控骰与免租争用同一个用卡机会和有限点券。
- 同街区集中建设能提高整片收入；拆除对手一层会同时削弱它对同街区其他房产的支援；抢地补偿防止低成本全图滚雪球。
- 降低无风险存款收益，保留股票波动、贷款利息、变卖折价和现金不足时的周转选择。
- AI 用公开信息评估控骰、回头、路障、工程队、拆层及街区收购，比较骰子分布和岔路终点；资金与行动限制和玩家一致。

## 最终自动对局

运行 `node tools/balance-sim.mjs 200`。每个人数及轮数组合 200 个种子，共 1,800 局。随后让一名完整策略代理对战经济代理，轮换完整策略所在座位，每种对照 1,800 局。总计 5,400 局，全部结束，无停滞。

## 检查与范围

59 项测试覆盖点券与购卡限制、恢复卡防循环、常规建设与工程队分别计次、拆层与联营、抢地补偿与距离、慢行与旧存档迁移、概率分布、预览不改状态、分岔/逆行/路障与实际走格一致、AI 只使用公开状态、随机先手完整轮数及先手破产。原有债务、资金守恒、100 局对局、2—4 人恢复、音效、模型与动画检查保留。

浏览器实际控骰买地并当地建设后再次建设按钮禁用；拆层使 3 级降到 2 级而不改变现金；用卡后所有卡禁用；两次购卡后余额由 150 降到 85 点券，奶币不变、购卡按钮禁用。落点面板在桌面、手机横竖屏可读和滚动。单文件 file:// 四人开局及落点面板正常，HTTP(S) 子资源 0。横屏 axe 41 项通过、0 项违规，1 项渐变/画布对比度待人工判断。

这些是程序代理、规则场景及桌面浏览器手机视口的证据。代理之间很多局仍以定时净资产结算，筹款并不等于破产；不承诺真人胜率或已经完成全部长期平衡。后续真人试玩应记录卡牌购买分布、分路使用率、局长和新手胜率，再调数值。原始最终结果在 BALANCE-RESULTS.json。
