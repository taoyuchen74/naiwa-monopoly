# 固定横屏体验

根据用户要求移除顶部横竖屏切换按钮，游戏只使用横屏布局。手机竖握时由页面自身顺时针旋转，横握时恢复正向；不申请系统方向锁或强制全屏，适用于拒绝相关权限的浏览器和离线HTML。单机与共用界面的联机客户端一致。

保留四向安全区映射、地图触摸坐标转换、面板焦点隔离和软键盘可视区域适配。实际旋转设备时，地图工具自动折叠。没有改变规则状态、存档或回放版本。

浏览器回归先在旧代码上复现“切换按钮仍存在”，再验证按钮不存在、竖握/横握始终横屏、设置中键盘焦点隔离、操作可达，以及纯界面旋转前后存档完全一致。原有旋转测试改为改变真实浏览器视口方向，没有删除拖动、缩放、滚动穿透、安全区和键盘检查；教程两行高度改用逻辑高度，避免将90度旋转后的物理宽度误当成行高。

Android Chrome、微信内置浏览器和iOS Safari仍待真机验证。旧四轮报告保留为当时版本的历史记录，本次固定横屏要求优先。
