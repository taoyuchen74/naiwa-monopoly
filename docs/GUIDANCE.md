# 情境引导与规则帮助

首次加载完成后，只用两行解释目标、掷骰和结束回合，不打开教程模态框。玩家可直接开始，不必确认提示。后续第一次掷骰、结束经营，以及第一次可购地、付租、建设、取得新卡、现金不足时，显示两行短提示和静态虚线控件标记。

购地、建设、付租和筹款提示放在原面板内容内，参与布局和滚动。地图提示放在操作栏上方的地图区域，不覆盖掷骰、卡包或结束回合。没有计时消失、自动滚动、聚焦抢占或动画。提示只跟随正常界面刷新，既不发送规则命令，也不消费随机数、不打开面板、不暂停AI。既有普通租金直接扣除时，结算后提示；原来可用购地卡的待付租选择保持先提示再决定。初始卡包不算新奖励，后续获得卡牌才触发；打开事件确认面板时先保留提示，确认后指向卡包。

热座换手、AI回合、破产/结束、角色室及无关面板不显示情境提示；换席会清除旧提示。教程进度属于同一浏览器所有席位共享的学习偏好，不是每席私有信息。手动打开规则帮助沿用原模态暂停行为；情境提示本身完全不阻塞自动行动。

## 偏好与退出

独立localStorage键：`naiwa-tutorial-v1`，结构：

```json
{"version":1,"disabled":false,"seen":["intro","buy"]}
```

仅在提示和目标控件实际可显示时记为已见，刷新不会反复弹出。同一提示持续显示到关闭或情境变化；不必先点击“知道了”才能执行游戏操作。“跳过全部”标记当前整组提示已见，“不再显示”关闭整套提示。设置中“重置教程”清空已见和关闭标志，退出设置后重新按情境显示。读取损坏或不可用时回落默认；写入失败不影响游戏，偏好在当前页面继续生效。重置写入失败时设置内说明仅本次生效。

不写入GameState、自动槽、手动槽、备份或JSON，导入与恢复不覆盖教程偏好。没有规则版本或存档schema变更。

## 搜索来源与键盘

`dist/rule-help.js`集中提示文案和帮助索引。银行上限、利息、休息日、手牌/点券与起点收益来自RULES；卡牌原文、基础价与时机来自CARDS/CARD_TIMINGS；建筑原文与上限来自BUSINESSES；车辆来自VEHICLES；模式预设及当前存档目标来自模式配置。卡价明确为基础价，实际优惠仍看商店。帮助中另列当前对局配置，避免自定义存档目标与预设混淆。

顶部“?”打开帮助，面板标题旁“规则”展开同一对话框内的搜索，不替换当前待决选择，不清掉欠款或改变阶段。空格分隔多个关键词采用AND匹配，支持中文名称和数值；结果和查询均按文本处理。Esc先收起内嵌帮助并回到规则按钮，再按原面板规则处理Esc。所有按钮为原生44px触控目标，搜索框16px，不强制滚动或跳转结果。

提示通过aria-describedby关联目标，文字仅在情境改变时以polite状态播报；AI期间没有教程播报。焦点不因提示出现而移动，键盘关闭提示后回到对应控件；模态焦点陷阱包括提示和搜索控件。标记采用虚线形状，并为键盘焦点增加双线；没有闪烁或脉冲，prefers-reduced-motion下也不引入过渡。

## 验证范围

单元测试覆盖偏好损坏/版本/存储失败、无状态副作用的情境选择、AI/交接抑制及规则搜索来源。真实Chromium在390×844与844×390执行跳过/关闭/重置与刷新、掷骰购地建设结束、两种租金流程、债务、实际卡牌奖励、搜索键盘和热座交接，并测量提示两行高度与操作按钮中心命中。全部既有规则、AI、存档、完整对局和浏览器套件继续运行。不是手机真机或系统软键盘验证。
