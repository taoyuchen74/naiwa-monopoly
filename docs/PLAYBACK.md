# 对局节奏与跳过

地图工具栏提供循环切换的1×/2×/3×、AI加速开关和“跳过”。设置也可直接选择速度。AI加速默认开启，开启时电脑演出采用3×；关闭后跟随所选速度。消息仍保留阅读下限，不承诺整场时长严格按倍数缩短。

速度只作用于角色移动、行动镜头、骰子、施工与粒子、行动间隔和消息剩余展示时间。环境时钟、音乐节拍不加速，角色室保持原节奏。出发/移动等规则仍逐次通过原命令层执行；不重抽骰子、不批量调用step、不改AI评分精度或交易结算。既有stateHash排除options和savedAt，测试比较的是完整规则状态、随机种子及命令顺序。

## 跳过边界

跳过收尾当前已存在的动画快照：骰子落到已经决定的点数，棋子移到当前规则位置，施工恢复真实模型与材质，拆除完成清理，转账效果执行一次收尾回调。它不会把玩家直接送到本次最终落点，也不主动推进下一条命令。后续移动和落地继续经过原循环。

普通播报可从当前演出队列移除；完整交易、资金不足、破产、结算和事件结果保持最短阅读时间，金额不再被短消息截断。普通消息至少600ms，交易至少1100ms，破产/结算和事件至少2200ms；隐藏或暂停时不消耗未读时长。所有永久日志保持原样，热座仍遵守原隐私过滤。

付款、分支、购地、债务、破产确认等任何打开的面板都不能被跳过按钮关闭。换手、角色室、结算期间也不执行跳过。按游戏对象、revision、当前玩家与阶段去重，同一动作快速连点只收尾一次；下一个真正的规则动作才恢复可用。按钮上的Enter/空格重复按键不触发新选择，避免长按跳过后顺带确认新面板。跳过不发送命令、不调用end或acknowledge。

环境烟雾不属于阻塞下一步的行动动画，避免持续烟雾让等待永远无法结束。粒子和3D文字无需为每笔变化增加计时器；简洁地图的资金标记由既有UI循环收尾，原始日志逐条保留。

## 计时与恢复

ActionPacer改变速度时只按比例重算剩余间隔，不重启整个动作。NewsFeed持有单个可取消计时器，每次重排会更新代号，过期回调无权推进新队列；暂停和切速不重复播放声音。EffectSystem先移除效果再执行回调，采用帧快照避免重入清理后继续访问已释放对象；新回调产生的效果留给下一帧。

速度与aiFast沿用独立浏览器偏好，同时保持既有存档options兼容；当前设备偏好按原流程优先于导入存档偏好。旧4×选项迁移为3×，新保存接受1/2/3；非法aiFast类型拒绝恢复。模式配置也允许初始速度3，预设原值不变。没有规则版本变更。

跳过代号、消息队列、视觉回调和等待期限都不写存档。换局或读档清理旧运行时状态，恢复当前真实位置，不重播旧历史，不保留“已跳过”锁存。

## 减少动态效果

prefers-reduced-motion默认关闭粒子、3D飘字、骰子演出和自动跟随/建设镜头；棋子采用静止定位。玩家仍可手动拖动、缩放或明确选择跟随。运行中更改该偏好会收尾视觉效果并停止自动跟随，不改变规则状态。消息进入和资金闪动也取消动画。

## 验证

单元测试覆盖三种速度的真实场景时钟、骰子最终朝向、施工材质/资源恢复、重入回调、单消息计时器、过期回调、快速跳过去重、烟雾非阻塞、旧存档及减少动态效果。确定性完整AI对局在三种速度、反复切换AI加速/跳过和中途恢复后，命令顺序与最终规则哈希相同。

常规真实浏览器用例在390×844与844×390验证切速/恢复、连续跳过后购地及结束按钮可用、交易金额、待决破产保护和AI破产结果。额外真实WebGL用例验证实际骰子/移动收尾及运行中媒体偏好变化。属于桌面Chromium及移动视口仿真，不是真机验证；运行方法见 [浏览器QA](BROWSER-QA.md)。
