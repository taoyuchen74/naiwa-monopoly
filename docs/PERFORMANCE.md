# 六人渲染与高手 AI 性能基准

固定种子 1701、滨河镇、六名角色、分布在地图上的交通工具与七类建筑。
AI 使用六组固定位置/手牌，包括重复路障卡；保留原版结果的 SHA-256。
原始统计与运行环境见 [performance-20261027.json](performance-20261027.json)。

环境为 Windows 11、i7-14650HX、Intel UHD / ANGLE D3D11、Chromium
156.0.8078.4。桌面为 1280×720、DPR 1；移动仿真为 390×844、DPR 3，
CDP 主线程 CPU 限速 4 倍。它们是同一台电脑上的仿真，不能当作真机手机帧率。
两个版本都使用同一份带移动 viewport 声明的测试页；未校准的初测不计入报告。

## 优化前后

| 模式 | 帧间隔 P50/P95 ms：前 → 后 | 绘制提交 CPU P50/P95 ms：前 → 后 | 高手单次决策 P50/P95 ms：前 → 后 |
| --- | --- | --- | --- |
| 桌面 | 225.4 / 236.2 → 129.9 / 139.7 | 225.0 / 235.9 → 129.6 / 139.4 | 1.6 / 4.1 → 0.8 / 1.5 |
| 移动仿真 | 218.3 / 331.5 → 172.8 / 232.7 | 215.2 / 329.1 → 171.2 / 229.0 | 9.4 / 21.9 → 5.5 / 14.3 |

帧间隔来自实际 drawFrame 调用的 performance.now 时间差；绘制提交计时包围
真实 WebGL/后处理调用，是主线程墙钟时间，可能包含驱动等待，不是独立 GPU 查询计时。
每种模式请求 32 帧，去掉开头两帧；得到 29–30 个间隔。AI 预热 12 次后测 60 次，
Game.restore 与渲染不计入单次决策计时。分位数采用 nearest-rank。
这是单机单轮前后对照，存在调度、温度与其他程序的波动；脚本用于重复验证方向。

两种尺寸、两版都约为每帧 **6,685 次绘制 / 26,037,729 个三角形**。
这是含阴影、AO 法线重绘和后处理的总提交量，不是唯一可见网格的三角形数。
**没有删减规则、路径分支或模型几何**；本轮降低屏幕空间成本，尚未解决大量绘制提交。
该六人重建筑压力场景优化后仍达不到 60 FPS，不能据此宣称已流畅。

菜单在请求 2.5 秒的计时窗口内，桌面绘制 12→0 次、移动 13→0 次；
静止模式分别为 12→0、15→0 次。阻塞渲染可能使计时窗口结束稍晚。
菜单冻结装饰动画；普通对局保留水面、角色呼吸等环境动画，因此仍持续绘制。
减少动态效果模式在移动、镜头缓动与特效结束后休眠，由输入、同步、尺寸变化或恢复唤醒。

## 画质分级

| 画质 | pixelRatio | 阴影边长 | GTAO 样本 / 相对渲染尺寸 | 后处理 |
| --- | --- | --- | --- | --- |
| 原版 auto | 至少 1.5，上限 2.5 | 4096 | 32 / 全尺寸 | AO、辉光、输出、FXAA |
| 桌面自适应 | 原生 DPR，上限 2 | 2048 | 16 / 全尺寸 | 保留 |
| 粗指针移动自适应 | 原生 DPR，上限 1.25 | 1024 | 8 / 宽高各一半 | 保留 |
| 省电 | 1 | 关闭 | 关闭 | 直接渲染；保留模型与环境材质 |

实测移动画布从 975×2110 降到 487×1055，AO 目标从 975×2110 降到 244×528；
阴影面积降为原来的 1/16。省电模式将闲置后处理目标缩为 1×1，切换画质前释放旧阴影目标。
这些是像素/资源预算，不是浏览器未提供的真实显存字节数。

## AI 精度与缓存边界

缓存只存在于一次同步 AI 决策中，在 finally 中丢弃。预览键包含步数、起点、首条支路、
前进/后退和完整路障分布；仍调用原引擎精确预览全部路线，保留原来的租金、点券与风险公式。
同一路线的效用和同一骰数组合复用；重复路障卡共享一次评分，但保留各手牌原有顺序与选择结果。
六组原引擎 preview 调用次数从 [952,1478,5226,1478,4599,947]
降至 [126,244,209,286,257,180]。跨回合、资金/位置/路障/拾取变化后不会复用旧结果。
六组完整状态、日志与随机种子逐项一致，另外有难度差异和完整对局回归。
优化后移动 AI P95 14.3ms，绘制开销仍远大于决策开销，本轮不引入 Worker。

## 资源释放与验证

活动场景两版均为 **443 个几何体 / 138 个纹理 / 46 个程序**。纹理尺寸显著变化，
数量相同不代表显存大小相同。预热省电/自适应切换后，三轮计数稳定为 443/138/68，
没有逐轮增长；额外程序来自两种渲染路径的着色变体。

补上 GTAOPass 原有 dispose 遗漏的 GTAO 和 blend 材质；私有几何体按集合释放一次，
共享几何体仍由模块缓存保留，避免销毁另一个模型正在使用的对象。
IslandScene.dispose 可重复调用，会取消 RAF、断开 ResizeObserver、移除监听、清除特效、
释放后处理/阴影/私有资源、销毁 renderer，并丢失其 WebGL 上下文以释放剩余 GPU 所有权。
模块级共享 CPU 模型缓存保留以供后续场景复用；WebGL info 是计数，不是显存测量工具。

验证命令：

- npm test：333 项通过，含渲染、AI、难度、完整对局与存档。
- npm run test:performance：桌面/移动共 6 项真实浏览器检查通过，含休眠/唤醒、
  暂停、隐藏信号、画质切换、三轮真实 WebGL 丢失/恢复与幂等销毁。
- 主页面 desktop 与 390×844 共 8 项交互回归通过：掷骰、用卡、购买、结束回合、地图手势、
  手动旋转、滚动隔离与输入视口收缩。

无头 Chromium 把所有测试标签保持为 visible，因此隐藏测试只注入 document.hidden
信号并派发 visibilitychange，实际运行应用监听、RAF 和 WebGL；不是操作系统窗口遮挡测试。
上下文丢失/恢复使用真实 WEBGL_lose_context 扩展。

复测（PowerShell，先 npm ci；运行时关闭其他压力测试）：
