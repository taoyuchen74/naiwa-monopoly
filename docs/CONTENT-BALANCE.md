# 护盾、换位、保险与经营事件

本轮从9张手牌、10个随机事件扩充为12张手牌、13个随机事件。三个新事件由事件格抽取，不占手牌。名称、描述、点券成本、目标、效果数值、时机和持续参数在`dist/content.js`中；UI仅展示描述、合法目标及已结算结果，不另行计算新规则。

## 新手牌

| 键 / 名称 | 点券 | 时机与目标 | 效果 |
| --- | ---: | --- | --- |
| ward / 奶伴护盾卡 | 30 | 行动前后，自身 | 存储一层个人事件护盾，保留至下一次负面随机事件或霉神到访。与神灵守护并存时先消耗本卡。不能挡租金、税费、疗养费，也不能叠加 |
| swap / 奶伴换位卡 | 40 | 掷骰前，一名存活且位置不同的对手 | 仅交换位置，双方来路、倒退、旧建设位置及旧银行到访资格清空。保留各自现金、点券、交通、神灵、已设步数、用卡次数与保险；不触发路障、起点、落地、购买或收费，之后正常掷骰 |
| insurance / 安心租金保险 | 40 | 掷骰前，自身 | 地产收费减免50%，含当前回合在内的三次本人回合结束。休养回合也计时；不覆盖收购、交易、公共费用，不免旅馆休养。同类保险存续时不能刷新或叠加 |

手牌上限仍为15，每回合最多买两张。费用只扣点券，满包拒绝购买；随机补给满包仍按原规则补偿60奶币，并受财运收入修正。新卡可由商店和原随机补给获得；研究所保留原五个项目。非法时机、非法对手、重复保护都不消耗卡、资金、随机数或命令计数。

换位的target是玩家id；原有控骰/路障仍是步数，地产卡仍是地块id。全部复用原card命令，只有引擎可写位置，目标页的查看与滚动不改变局面。换位后银行/商店按新位置及原有办理规则判断，清除来路避免倒退穿越不真实的旧路径。

## 新随机事件

| 事件 | 参数与范围 | 持续和重复 |
| --- | --- | --- |
| 奶币物流分红 | 股票3上涨8%；触发者每股分红4奶币，名义上限120，财运可提高实际收入。未持股仅改变行情 | 即时；股价仍限制在20—500，更新历史及变动；周日也能触发事件行情/分红，休市只禁止交易 |
| 社区经营节 | 触发者已建成收费设施的名义收费提高15%，公园点券、研究产出和空地费用不变 | 本轮及之后2轮；存绝对截止轮数，重复仅延长期限，不乘叠。同一业主在期限内新增或收购的收费设施也适用 |
| 设施安全巡检 | 触发者最高级的一处收费设施暂停收费，同级取最小地块id，公园/研究所不参与 | 本轮及下一轮；检修随地块归属保留，拆至空地清除。没有目标时无效果，也不消耗事件护盾/神灵守护 |

事件护盾先于神灵守护抵消整个负面事件，包括该事件附带的行情变化；无护盾才消耗神灵守护。休养事件即使附有补贴，仍沿用原神灵逻辑视为一个整体的负面事件，抵挡时两部分均取消。正面事件不消耗保护。

收费顺序明确如下：

1. 公园/研究所免费；业主休养或设施检修不收费，保留免租卡，也不抽旅馆天数/商场倍率。
2. 已备快乐免租卡抵消整笔费用并消耗一层，旅馆不安排休养；保险仍保留，但结束回合照常计时。
3. 无豁免时生成原名义费用，再加经营节倍率并四舍五入。
4. 对该金额合并保险、霉运、角色折扣后做最终一次支付取整。实际减免后金额同时记入债务、收款方和付款记录；筹款后settle不再重复折扣。
5. 保险每次本人end递减。经营/检修截止轮数含该轮，下一轮失效；不依赖现实时间或动画速度。

## AI与存档

轻松AI维持简单经营，新增护盾到手且无同类/神灵守护时使用，不主动做换位或保险组合。标准与高手将新卡纳入既有公开局面候选：护盾按有限风险准备值估值；保险比较当前预期租金、50%减免和最多三个剩余回合；换位比较各对手位置下可选骰数的预期收益，扣除换位成本和对手受益惩罚，再按原难度门槛决定。路线预览按起点分别缓存，不修改RNG。商店先满足原控骰/工程/免租需求，再按已有保护、风险和换位收益补充新卡。

规则版本提升至8，存储schemaVersion仍为1。旧规则7及更早快照补齐`eventWard=false`、`insuranceTurns=0`、`operatingUntilRound=0`；地产检修字段可省略，保留原资产、地图、当前阶段和随机种子。保险计数、期限及事件outcomes均校验，损坏数据拒绝恢复。四槽、备份、JSON和命令去重继续有效，新效果参与stateHash。新抽取池改变后续随机结果，历史命令重放应使用对应规则版本；不宣称规则7与8产生同一条后续轨迹。

## 可重复模拟

沿用现有economy-sim/talent-sim的Game.ai批量循环，新增`tools/content-sim.mjs`记录胜率、轮数、资金变化和新卡使用。每组两张地图×三种难度×36个固定种子，共216场六人50轮对局；角色起始席位循环、随机先手、天赋开启。并列分摊胜场，每个角色每场均参赛。原始分组统计、参数与事件/卡牌次数见[机器可读结果](simulations/decision-content.json)。

基线首先在提交`9ebb0243c47f2d9594078f0476765b88965db277`运行。复跑入口：

```sh
node tools/content-sim.mjs --variant=baseline --seeds=36 --rounds=50 --output=artifacts/content-baseline.json
node tools/content-sim.mjs --variant=candidate-random --seeds=36 --rounds=50 --output=artifacts/content-candidate-random.json
node tools/content-sim.mjs --variant=candidate --seeds=36 --rounds=50 --output=artifacts/content-candidate.json
node tools/content-sim.mjs --variant=final --seeds=36 --rounds=50 --output=artifacts/content-final.json
```

baseline模式在当前实现中恢复旧抽取池并禁止购买新卡；其216场所有分组结果已与旧提交基线逐项一致。两个候选也通过重复运行全表比较。重复验证不增加独立样本量。候选随机补给版不主动买新卡，完整候选加入购买策略；最终版保持完整策略，只将经营加成25%降至15%、保险45降至40点券，以限制收费复利并降低防护获取门槛。

| 版本（各216场） | 平均结束轮数 | 现金变化标准差 | 平均绝对现金变化 | 平均终局现金/人 | 破产率/参赛者 |

| 旧9卡/10事件 | 50.00 | 398.79 | 258.36 | 1834.30 | 15.90% |
| 候选：仅随机补给新卡 | 50.00 | 394.06 | 252.40 | 1744.09 | 18.13% |

资金波动指每名玩家在轮边界的现金差额合并后的总体标准差，包含买卖、借还及最后一个结束区间，既不是股价波动也不是净资产波动。所有样本都达到50轮上限，因此平均结束轮数在此样本中不敏感，不能据此断言实际时长不变。

## 回归范围

专项测试覆盖费用、手牌上限、护盾与守护优先级、合法/非法换位、无重复触发、保险计时与叠加、预览/实收/债务一致、三类事件、迁移及四槽去重、AI确定性。真实Chromium交互覆盖三张卡的使用与恢复，以及三个事件从移动触发、显示实际结果到确认继续。沿用全部规则、天赋、AI、完整对局、旧AI指纹（仅归一化新增默认字段与规则版本）及存档测试；移动浏览器为桌面视口仿真，不宣称真机验收。
