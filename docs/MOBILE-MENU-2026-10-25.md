# 手机开局布局

开局面板拆成可滚动内容和固定底部操作区。开始按钮始终保留在面板底部，角色、天赋和设置在内容区滚动，避免短屏幕需要翻到底才能开局。

650像素以下的横屏高度采用两栏：左侧角色与天赋，右侧地图、时长、人数、电脑强度及高级设置。360像素以下的横屏高度简化天赋说明正文，完整天赋仍可在游戏的角色天赋面板查看。竖屏和桌面保留单栏。布局宽度依照实际游戏容器，兼容游戏内旋转而非只依赖浏览器的物理视口。

验证：149项检查通过。浏览器在568×320、667×375、320×568、390×844、1280×850下核对开始按钮边界和中心点击命中；均在视口内且未被遮挡。另验证390×844通过游戏按钮切成横屏时按钮仍可点击；有旧存档的568×320布局同时保留新开局入口和继续入口，并实际继续存档成功。无页面错误。这些是桌面浏览器视口与旋转模拟，未测试真实手机设备。
