# 用户三视图与批注重做核对

## 当前需求

| 用户要求 | 落地结果 | 验证 |
|---|---|---|
| 业主及功能区分 | 绿、红、蓝、紫边界、旗帜、墙面和屋顶；六类建筑独立轮廓及三级外观 | 全建筑配色测试、ownership-color-overview.png |
| 三视图模型及奶狗 | 奶蛙奶鼠连续曲面重建；奶狗四足、棕垂耳爪、米白胸腹与上翘尾 | 角色三面检查、渲染测试 |
| 开局选人数 | 2／3／4 人，四名角色，规则、AI、站位、HUD、存档同步适配 | 多人数完整对局与旧存档测试 |
| 名字下的小字删除 | 选角仅保留头像与名字 | 页面检查 |
| 图标美化 | 品牌、奶蛙、奶虫、奶鼠、奶狗头像重绘 | 实际页面检查 |
| 旅行券删除 | 删除整行旅行券标题及编号 | 页面检查 |
| 大笑动作 | 观察 B 站视频，捧腹、闭眼、露齿、肩腹抖动、前后俯仰 | 动作测试、角色室检查 |
| 中央装饰房屋 | 无玩法对应的中央五栋装饰楼及大雕像删除，仅保留公共景观 | 地图总览检查 |
| 显眼消息 | 中央短消息顺序弹出，打开窗口和暂停时配合暂停，历史保留完整内容 | 队列测试、实际升级与记录检查 |
| 地图不方正 | 自然海岸、弧形街道、弯曲捷径，按路向排列地产与功能建筑 | 48 节点连通、地块朝向、海岸范围与浏览器检查 |

保留背景音乐、动作音效、空地虚线、建拆动画、银行股票道具、自动存档与手机直接打开链接试玩。账号、云存档及在线联机属于用户此前明确提出的后续扩展，不将本机存档冒充账号系统。

本次建模与界面为原创轻量实现，参考来源及实际验证限制见 SOURCES.md、VALIDATION.md。

当前七项追加要求已单独验收，见 POLISH-2026-10-23.md；当前规则以 RULES.md 为准，先前三级与单卡限制属于旧版。
