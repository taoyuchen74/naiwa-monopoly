# 手机方向与六角色天赋

| 角色 | 自动天赋 | 触发与限制 |
|---|---|---|
| 奶蛙 | 稳稳经营 | 常规加盖花费减少 15%；正向经过起点额外 +80。名义资产成本不变，不产生拆建套利。 |
| 奶虫 | 细水长流 | 每次出发 +60；到店卡片点券价八折，向上取整。 |
| 奶鼠 | 精打细算 | 实际租金支付八折；收购卡价格再九折，收款方只收到实际付款。 |
| 奶狗 | 傻狗有傻福 | 出发时 50% +240，否则摔丢最多 40，最低为零。不改动本次步数。随机结果与存档种子一致。 |
| 奶蛋 | 躺着也能赢 | 出发 +75；每四次出发给最低级自家地产免费 +1，同级取地图编号较小者，最高五级，不占普通建设次数。没有地产时不补建房屋。 |
| 豆奶 | 暖心补给 | 非租金费用五折；每三次出发 +20 点券与一张野生狗奶，卡满按原规则补偿。 |

休养跳过行动不计出发；恢复之后继续。天赋先结算并播放消息，然后自动掷骰，不需要再点击一次。talentReady 与 departures 进存档，读档不重复领钱或建设。旧存档缺少 talents 时迁移为关闭，防止改变既有对局；新局默认开启，可取消勾选。通过地图“天赋”可看本局状态。

## 横竖屏

按钮始终标出下一次方向。先即时切换游戏布局；粗指针设备尝试系统全屏与 ScreenOrientation.lock，不支持或被拒绝仍保留布局旋转。逻辑尺寸与画面方向同步，媒体样式、3D 画布尺寸、点击与拖动坐标均对应。切换不更换 Game 实例、不修改存档数据。退出系统全屏后仍能继续操作。未保存方向到存档，重新打开按设备当前方向显示。

## 验证

- 最终 86 项检查通过；原有基础规则测试明确关闭天赋，新增天赋测试覆盖六名角色、新旧存档、出发恢复、折扣收款、满包补给、建设五级与五／六人完整对局。
- 540 局最终天赋模拟：2／4／6 人 ×20／50／80 轮 ×60 种种子，均能结束及恢复，中间状态也抽检有效。结果见 TALENT-RESULTS.json。
- 奶蛋最初每回合建设接近包赢，已改为每四次出发建设。最终六人标准 50 轮样本，奶蛋 35/60 胜，明显强势；这是用户指定的强势定位，未声称竞技平衡。
- 浏览器 390×844 视口中，横屏布局为 844×390，再切回竖屏不丢进度；六名玩家存在、无页面横向溢出、无运行错误。
- 实际按旋转后物理坐标点击地图第 1 地块，回调命中仍为第 1 地块；相同变换用于拖动与双指缩放。另有纯函数坐标测试。
- file:// 单文件约 2.68 MB，六人开局、旋转往返、字体正常、HTTP(S) 子资源为零、运行错误为零。
- 实际真人奶蛋出发，先进入 departure 展示天赋，按钮禁用，随后自动移动并到达购地弹窗，无第二次掷骰点击。
- 这是桌面 Chromium 的手机视口测试，不是实际安卓硬件、系统全屏 API 或微信内置浏览器认证。模型是基于可见参考制作的程序模型，未提取视频资产。
