# 后续路线

## 角色和参赛人数

角色信息在 `dist/content.js` 的 CHARACTERS 注册表，规则状态以 players 数组保存。本版已完成 2—4 人设置、四名已制作角色、位置避让、动态 HUD、AI 及人数对应的恢复校验，兼容旧三人存档。超过四人的扩展需先补充已核验角色。

在抖音、B站、小红书等中文平台核对奶粉、奶蛋、奶茶、豆奶的具体形象，保存原始来源，区分同名变体。先出角色对照与转面预览，再完成高低模、UV、材质、骨骼蒙皮、基础动作与手机 LOD；现有轻量角色生成器作为备用画质。

## 账号与云存档

保留游客即时试玩，新增账号注册登录、退出登录、云存档、跨设备继续和战绩。先确定适合用户发布地区的身份与存储服务，再实现服务端鉴权与存档所有权校验。存档版本与纯规则状态独立于本地存储，新增 repository 适配层；处理游客绑定、同步冲突、重复提交与设备时间不可信等情况。

本版使用 localStorage 及 JSON 导入导出；没有账号接口、服务器数据库、排行榜或网络联机。不能把本机存档视为可受信任的竞技成绩。

## 在线联机

与账号阶段分开：房间、服务端权威状态、命令校验、断线重连和回合超时。复用确定性规则引擎，服务端持有随机状态。单机与联机存档分离。
