# 后续路线

## 角色和参赛人数

角色信息在 `dist/content.js` 的 CHARACTERS 注册表，规则状态以 players 数组保存。目前支持2—6席、每席独立选择真人或电脑，含同设备热座和纯AI旁观，六名角色为奶蛙、奶虫、奶鼠、奶狗、奶蛋、奶茶，均有可关闭的专属天赋。已实现人数对应的恢复校验、高级阵容与逐席电脑难度；旧豆奶存档会迁移为奶茶并保留资产。六人完整对局、迁移和存档保护已有自动回归。

后续新增角色应先核对形象与原始来源，区分同名变体，再提供角色对照与转面预览。现有角色是程序生成的原创重建模型；更细的模型分级、材质与手机LOD仍需依据实测推进，不把参考视频或桌面仿真当成源模型授权或真机验证。

## 自动验证与设备覆盖

已提供单元测试、两种手机视口的轻量Playwright交互套件和CI，并保留更广的移动端、无障碍、渲染生命周期检查。当前基准和浏览器测试使用桌面Chromium/移动仿真；真实安卓、iOS、系统软键盘及不同移动GPU的验证仍待安排。测试范围和复测方法见 [浏览器QA](BROWSER-QA.md) 与 [性能报告](PERFORMANCE.md)。

## 账号与云存档

保留游客即时试玩，后续新增账号注册登录、退出登录、云存档、跨设备继续和战绩。先确定适合用户发布地区的身份与存储服务，再实现服务端鉴权与存档所有权校验。本机已提供独立存档格式版本、集中迁移和repository适配层，以及3个手动槽、1个自动槽；详见 [存档说明](SAVE-FORMAT.md)。云端仍需处理游客绑定、同步冲突、重复提交与设备时间不可信等情况。

本版使用 localStorage 及 JSON 导入导出；没有账号接口、服务器数据库、排行榜或网络联机。不能把本机存档视为可受信任的竞技成绩。

## 在线联机

与账号阶段分开：房间、服务端权威状态、命令校验、断线重连和回合超时。复用确定性规则引擎，服务端持有随机状态。单机与联机存档分离。

已实现配置驱动的短局、经营挑战和离线每日种子挑战，默认参数与自动模拟范围见 [模式说明](MODES.md)；不含联网排行或防作弊认证。
