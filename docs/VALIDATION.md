## 实际限制

- 使用的是桌面 Chromium 的手机视口模拟，没有在真实 iOS/Android 设备上测帧率，不能承诺具体手机的 30 帧表现。提供省电画质、动画倍速与简洁地图降级。
- 四个角色为程序制作的原创风格化模型，提供关节层级和程序动画。精雕模型、UV 烘焙、完整蒙皮与专属动作捕捉属于后续阶段。
- 手机文件管理器可能限制本地 HTML 执行，可用部署版；单文件版、localhost 与部署版存档不同源，需手动导出导入转移。
- 模型与图像采用原创实现。声音包含公版旋律重新编排和社区小游戏的 1.05 秒短笑声，具体来源与使用范围见 SOURCES.md。
- 2—4 人与新增奶狗已实现；账号、云存档、更多角色与在线联机仍属后续扩展。
