# 模式配置

开局进入“席位与高级设置 → 旅行模式”。经典使用自选轮数/资产；三种预设覆盖轮数、资产和默认节奏，地图、席位、角色、AI难度和天赋仍可配置。

| 模式 | 轮数 / 默认速度 | 每席初始条件 | 卡池 | 目标 |
| --- | --- | --- | --- | --- |
| 经典 | 自选20/30/50/80，默认50 / 1 | 自选现金、点券，无贷款地产 | 全12种 | 存活优先，净资产排名 |
| 短局 | 20 / 2 | 3200现金、60点券 | 全12种 | 同经典 |
| 经营挑战 | 20 / 2 | 3200现金、60点券、800贷款、两块一级住宅 | 排除抢地、拆除、换位 | 结算时存活且净资产≥5000，可多人成功 |
| 每日固定种子 | 30 / 2 | 3200现金、60点券 | 全12种 | 同经典 |

贷款是已有债务，不另发800现金。初始地产免费分配：按地图property地块ID顺序，每席轮流一块，重复两遍，不消耗随机数。块数相同，位置与名义价值可能不同。初始控骰、免租、补给三张卡按卡池过滤。短局减少轮数、默认轻快动画，不跳过确认或降低规则精度。

每日种子是 `naiwa-daily-v1:YYYY-MM-DD` 的FNV-1a 32位哈希（0替换为1）。日期用本机年月日，不按UTC切日、不访问网络。配置保存日期及解析后的种子，跨日读档不重算。同日只有其他设置与操作序列相同才可复现。角色、席位、难度、路线仍可选；**修改日期、配置、操作或存档即可改变成绩，没有防作弊能力或排行榜认证**。

## Schema与模块边界

唯一实现为dist/modes.js：modeConfig生成预设，validMode校验，applyMode仅设置初始条件，modeProgress只读已有净资产。JSDoc/checkJs及dist/domain.d.ts中的ModeConfig检查边界；机器可读约束见 [mode-config.schema.json](mode-config.schema.json)。

```json
{
  "configVersion": 1,
  "id": "business",
  "rounds": 20,
  "speed": 2,
  "initial": {"cash": 3200, "tickets": 60, "loan": 800, "propertiesPerPlayer": 2, "buildingLevel": 1},
  "allowedCards": ["dice", "block", "turn", "shield", "recover", "build", "ward", "insurance", "slow"],
  "goal": {"type": "netWorth", "target": 5000},
  "dailyDate": null,
  "fixedSeed": null
}
```

允许受边界约束的自定义配置；id是展示分类，并非不可变预设签名。掷骰、收费、银行、AI和结算继续使用原引擎。随机卡仅从允许卡池抽取；购买、使用、切换研发均验证卡池。明确指定的禁用奖励（天赋、事件、已有研发项目）走原60奶币补偿路径，不另抽卡；手牌上限和收入倍率保持原规则。

目标只在原结束条件触发时判断，不因中途达标提前结束。资产榜与挑战成败分别显示，每席有净资产当前/目标和具名进度条。失败原因区分破产、轮数用尽未达标、提前结束未达标；无人成功时winner=null，排名仍生成。

规则版本10；存档schemaVersion仍为1，增加mode对象，configVersion独立为1。旧档缺少mode时补经典配置、沿用maxRounds，不改玩家资产。仅创建时发放初始资产，恢复不会重发地产/贷款或读取当天日期。未知配置版本、轮数不一致、无效卡池/目标/日期、持有禁用卡均拒绝恢复。模式参与stateHash，四槽、备份、JSON和热座仍走既有存档流程。

## 模拟

复现：`node tools/mode-balance.mjs 40`，完整结果见 [data/mode-balance.json](data/mode-balance.json)。每模式40场，共160场；3名标准AI、滨河镇、随机先手、固定默认角色奶蛙/奶虫/奶鼠、启用天赋。经典/短局/经营种子1—40，每日为2026-10-01起连续40天，全部运行至原规则结算。阈值不影响AI决策，故在同一经营终局上比较目标。

| 模式 | 平均轮数 | 净资产P10 / P50 / P90 | 各席资产榜首次数 |
| --- | --- | --- | --- |
| 经典 | 50 | 5667 / 7974 / 10853 | 6 / 32 / 2 |
| 短局 | 20 | 3719 / 4637 / 5949 | 7 / 33 / 0 |
| 经营挑战 | 20 | 2917 / 4104 / 5314 | 5 / 30 / 5 |
| 每日 | 30 | 4348 / 5619 / 8014 | 4 / 36 / 0 |

初试10000目标，40场120席无人达成，因此未采用。最终5000目标19/120席成功（15.83%），19/40场至少一席成功（47.5%）；4500与5500对照为32.5%与8.33%。160场均无破产。短局平均轮数减少60%，不推断真实分钟时长。该组奶虫优势明显，结果不能证明角色公平或真人胜率；5000是有难度的初始默认值，其他人数、角色、高手AI还需扩大样本。这是自动模拟，不是真人试玩或真机验证。
