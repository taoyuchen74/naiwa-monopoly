# 拍卖与玩家交易（规则11）

本次用于至多一名真人及电脑的单机对局，纯AI也可拍卖。多真人热座沿用原拒购流程，不开放这两项新功能。

## 状态机

无人地产：buy → 接受按标价购买 / 拒绝后auction → end。抵达者仍是current；auction.actor独立表示有权竞价的玩家。所有存活玩家按抵达者起的循环顺序参加，抵达者也可竞拍。起拍价为标价50%向上取整至10，最低10；每次最低加20，可输入更高整数报价。只能使用当前现金，不取存款、不借款、不抵押。最高报价者暂不行动；放弃者永久退出本场。无报价且全员放弃为流拍，土地保持无人。只余最高报价者即成交，从其现金扣实际报价支付银行，生成零级地契；不会凭空产生另一玩家收入。若无人还能加价，仍需逐人放弃。起拍/加价/现金上限保证有限终止。只有抵达者竞得才能立即当地建设。

玩家交易：己方roll/end → negotiation → AI接受并原子结算 / 拒绝 / 真人撤回 → 原阶段。不在债务、移动、待决购地、拍卖或事件中发起。报价是双方现金、地契ID及手牌下标组成的两包，提交即真人确认并冻结；对手为存活AI，审核按钮由引擎按AI估值确认，不允许UI伪造接受。AI不主动提出报价。报价待决时禁止其他规则操作，不能反复更新已确认内容；取消后可重新报价。

现金必须是非负安全整数且各自预付得起，不净额融资、不动存款；最终余额也须安全。地产须存在、属于出让方且未标记抵押，建筑、项目、关闭期限随地契完整转移。当前没有抵押功能，仍拒绝mortgaged=true或mortgage>0地契。持有正常银行贷款不等同于待筹款债务；贷款仍由原借款人承担。不交易贷款、股票、交通工具或点券。卡牌使用手牌下标，重复下标/重复地产、非法卡、禁用卡、空报价、同人或破产方、任一债务均拒绝；转移后手牌最多15，不触发溢出换钱。双方资产检查全部通过才转移，失败不产生部分付款或丢卡。成交后清除转出方的建设许可；接手不会产生远程建设许可。

## AI与守恒

AI拍卖按地产成本、联营及剩余经营时间估值，轻松/标准/高手保留不同现金准备金；不额外抽随机数。交易按双方交出/收到现金、地产经营价值和卡牌点券成本的奶币效用估值，标准与高手要求一定溢价，并保留准备金。AI只在其 own 手牌参与报价时使用具体牌值；界面不会列出对手手牌，只允许按公开卡牌种类请求（引擎将种类解析为合法下标）。

交易前后整桌现金、存款、贷款、每块地契及每种手牌数量不变。拍卖现金变化恰等于向银行支付的中标价，净资产不要求不变（拍卖低价取得按成本估值的土地）。不以“所有人净资产不变”替代真实资金流验证。

### AI估值数值

地产效用为成本 ×（0.75 + min(0.25, 剩余轮数/80) + 同街区其他自有地数量 × 系数），取整数；高手街区系数0.15，其他0.08。它是经营启发式而非现金收益或规则租金。拍卖上限为 min(现金−准备金, 地产效用×倍率)：轻松700/0.8，标准550/0.95，高手450/1.05，下限0；每次只出当前最低价，无随机扰动。

交易一包价值 = 现金 + 地产效用 + 卡牌点券价格×3。AI要求收到价值至少为交出价值的轻松1.00/标准1.08/高手1.15倍，成交后现金不得低于 min(原现金, 准备金300/450/550)。不因为报价净额可负担就允许任一方超出原现金支付。

## 存档及回放

保存完整auction/negotiation待决状态，读取时验证参与者、价格、退出集合、报价资产与原阶段一致；旧存档缺字段迁移为null。规则提升到11，规则10回放明确不兼容，旧游戏存档仍迁移；不将旧命令按新拒购规则误播。

## 边界用例（实施前约定）

- 拒购后暂停原回合；真人即使不是落地者也能竞价；非法玩家、重复命令、低价、超现金、退出后再投、最高者自抬均拒绝。
- 所有人放弃流拍；单人出价后其余放弃成交；破产者不参加；资金不足全员放弃有限结束；存读后继续结果一致。
- 组合报价先完整校验；重复/不存在/他人/抵押地契、重复卡、超手牌、超资金、安全整数溢出、非法阶段与债务拒绝且状态不变。
- AI接受/拒绝/撤回无竞态；两向卡牌按原下标批量移除，卡牌重复种类仍守恒；地产附属状态保留。
- 确定性种子、完整对局、回放终态、存档迁移、资金与资产守恒及手机横竖屏真实交互。
