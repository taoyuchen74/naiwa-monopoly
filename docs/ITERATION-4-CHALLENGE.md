# 第四轮：森林经营挑战入口

首页新增“森林经营挑战”。先展示条件与目标，再进入原有席位设置；取消介绍、退出未保存的席位设置，都不会覆盖正在保存的旧局。真人+AI、同设备热座与纯AI旁观复用原有设置和隐私交接。

快捷入口解析为内置地图4与已有 `modeConfig({id:'business'})`：20轮、3200现金、60点券、800贷款、每席两块一级住宅，结算时存活且净资产达到5000；禁用卡名称由允许卡牌列表与统一卡牌内容反推。介绍页直接读取配置，不另存一份规则数值。

新增 `UI_PRESETS` 为只读UI表，`resolvePreset()` 每次返回独立配置。存档与回放只记录已有地图编号及ModeConfig，不增加presetId，不改变规则、存档或回放版本。离线包也具有同一入口。

分岔只显示 `Game.routes()` 返回的合法路线；省步数由当前地图的入口、汇合点和路径计算，标题明确标为“全程省X格”。实际落点仍由 `Game.preview()` 给出，包含路障截停及现有费用范围；没有把几何省步误当作必然到达，也没有预测未产生的天气。天气描述沿用当前影响、剩余期限和下次抽取轮次。

结算使用现有 `modeProgress()` 和资产分项，增加“距离目标还差X奶币”，保留轮数耗尽、提前结束和破产原因。没有奖励货币或成长系统。

## 验证范围

专项单元覆盖预设只读/配置隔离、未知预设拒绝、三种席位类型、原有手动存档与JSON恢复、合法路线与省步计算、封路/路障独立、预览哈希不变及结算差额。森林经营模式执行2—6人、三种AI难度共15局完整对局，中途实际切换为恢复后的实例；其中一局完整命令回放到相同最终哈希。

浏览器以实际按钮完成介绍/取消、焦点与Tab隔离、席位配置、热座换手恢复、手动保存/读取、刷新继续、路线预览/选择和资产展开。真实WebGL另外从快捷入口切到森林并开局，确认仍有3D画布、未降级为简洁地图。随后切换六种视口并注入四向安全区，检查天气、教程与资产栏互不遮挡；360×640下实际滚动教程并点击“跳过全部”、开关资产抽屉。修正了玩家栏在已预留安全区的父容器中重复扣除安全区的问题；短屏教程独立滚动，保留44px按钮。

这些完整对局用于兼容检查。第三轮50轮经典模式的角色统计不能直接证明20轮挑战的难度已平衡；本轮没有调数值，也没有声称完成真人平衡。

完整CI、网页/离线包发布和线上版本核对结果见本轮PR。Android Chrome、微信内置浏览器和iOS Safari均未获得真机结果，仍待人工验证；软键盘为视口收缩仿真。

本地最终结果：532项单元测试全部通过；14项浏览器交互/离线包检查通过；真实WebGL入口与六视口安全区专项1项通过。类型检查与改动文件检查通过。
