# 同设备热座与旁观

开局的“席位与高级设置”配置2—6个席位。每席独立选择真人/电脑、角色和AI难度；真人不使用AI难度，但选择会保留。第一席角色也可在主菜单选择，其余角色可固定或随机，不重复。所有席位使用相同起始资产、卡牌与经济规则。

- 0名真人：纯AI旁观，只提供公开地图、过程及结果，不提供账户操作。
- 1名真人：保留单人＋AI流程，真人可在任意席位；AI回合可只读查看该真人的原有账户，不会操作AI账户。
- 2—6名真人：启用热座。每名真人接手前出现“请交给玩家N · 角色”遮罩，确认后才开放私有界面。混合席位中AI照常自动行动。

## 状态清单

| 状态 | 含义 |
| --- | --- |
| players[i].human | 存档中真实席位类型，true为真人、false为AI；沿用原字段，未另建易失配的第二套席位类型 |
| players[i].character / difficulty | 各席角色和AI难度，均随存档记录 |
| handoff=null | 没有待确认交接；是否能操作仍取决于当前玩家、真人类型、存活状态和原规则阶段 |
| handoff={playerId} | 此真人尚未接手；必须指向当前存活真人，且对局有至少两个真人席位 |
| phase | 保留roll/buy/debt等原阶段，不把交易或债务清掉来显示遮罩 |
| revision / commandSequences | acceptTurn和lockTurn也计入命令历史，重复确认不消费第二次计数 |

创建及end推进至下一名真人时，prepareHandoff设置待交接；进入AI回合时为空，已破产席位跳过，结束比赛时清空。交接期间命令返回HANDOFF_REQUIRED，自动移动/天赋/AI节奏也暂停；acceptTurn只解锁当前真人，不掷骰、不结算费用、不更换阶段、不消耗RNG。

纯Game.restore保持确定性，供存档、测试和回放使用。真实UI的继续、读槽、导入及恢复备份入口会通过lockTurn重新锁住已确认的热座真人回合，因此中途债务或买地存档也先交接。已经待交接的快照直接恢复原状态。单人及旁观没有额外交接步骤。

## 隐私与操作边界

| 公开信息 | 私有信息 |
| --- | --- |
| 角色、席号、真人/AI类型、位置、公开现金与净资产、地产、已使用的公开效果、公共报价及结算结果 | 手牌内容、持仓股数/成本/成交历史、存贷款明细和这些账户的操作 |

accountPlayer是卡牌、股票、银行、商店和地产操作页的统一查看者。热座只返回已确认的当前存活真人；AI、交接中及结算后不返回私有账户。其他人的角色详情只生成公开摘要，不把完整账户放进隐藏HTML；单人模式保留原只读查看流程。

UI提交者从当前已确认账户取得，不再写死第0席。账户控件在AI回合禁用；事件处理器与send再次检查身份，旧面板残留按钮或伪造点击不能把资金操作发给AI或另一席。原命令层仍校验当前玩家、阶段、载荷和序列。

每次换席会清除旧面板内容、选择弹层、消息队列、延迟ARIA播报和toast。遮罩使用原模态焦点隔离，背景inert；Tab/Shift+Tab不离开，关闭/折叠入口隐藏，Escape不能跳过确认。公开消息及历史记录会遮去新手牌、股票数量/名称、银行明细，兼容导入旧日志；已使用卡牌等公开行为仍保留。AI事件只显示公开过程摘要。

这是同设备正常交接的防误看、防误操作，不是账号鉴权或加密隔离。完整localStorage和JSON仍包含整桌规则状态，存档导出属于整桌管理工具；不防主动读取存档、开发者工具或屏幕旁观。没有引入网络或账号。

## 存档和兼容

规则版本为9，schemaVersion仍为1。旧单人/AI存档的human字段直接沿用，缺少handoff时默认空；多真人文件缺少handoff时，当前真人会默认待交接。错误玩家id、非真人、破产玩家、结算后或单真人的待交接对象均拒绝恢复。各席类型、交接状态和计数参与stateHash；四槽、备份、JSON导入导出继续工作。

同一快照和包含交接命令的同一操作流可重放。重新进入UI触发的lockTurn属于显式命令，会递增版本；不宣称UI重新锁定后的哈希与纯restore相同。旧版本回放仍应使用对应规则版本。

## 验证与范围

引擎回归用确定性合法操作策略代替真人输入，完成两张地图×2—6席×全真人/混合×两个种子的40场20轮对局，在每次换手存取档并逐条重放比较最终哈希；另完成两场六席纯AI旁观对局。这些是自动规则测试，不是真人试玩记录。

真实Chromium在390×844和844×390验证逐席配置、换手Tab/Shift+Tab/Escape、私有DOM清理、第二席银行与股票实操、AI禁用及残留按钮、真实刷新后的待交接债务恢复、纯AI开局。原单人、卡牌、存档、模态、WebGL失败等流程继续运行。未宣称真机验证。

新增界面后脚本仍受1MiB未压缩及300KB gzip预算约束，未增加前端框架；原先十进制1,000,000字节阈值相应改为1MiB，构建记录报告实际尺寸。
