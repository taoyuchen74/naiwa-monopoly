# 受约束的自定义地图 v1
本设计先于实现。仅导入 JSON 数据，不导入模块、脚本、HTML、模型或URL；不提供执行表达式的扩展点。
## 格式与边界
顶层为 schemaVersion:1、id、name、description、tiles、branches、pointStops、eventPool、startingCash、victory。内置两图也使用此格式；独立保存的既有3D摆位保留精确浮点值。
tiles 有16—64格，id必须唯一、连续0至N−1；0是唯一start。每格定义kind、name、description、x/z、group、price、next；kind仅允许现有十类(start/property/event/bank/shop/stock/hospital/spirit/rest/tax)。组0—5，坐标−24至24，地价整数100—2000；名称1—32字、描述0—240字，仅纯文本，禁止HTML元字符和控制字符。可选yaw/lotX/lotZ/facing是内置图兼容布局数据，不允许外部资源。
每格1—2条唯一有向边，引用现有ID。next[0]组成包含起点的至少12格主环，next[1]是支路入口；branches最多两项{from,merge}，fork唯一，merge必须是主环上的另一个节点。支路至少有一个专属中间格、不再嵌套分岔、不交叉共享中间格，最终抵达声明汇合点。全部格子须从0可达并能返回0，不能有游离小环、死路或无声明分岔。倒退优先使用实际行走历史，无历史时按明确的主路/支路前驱返回。
至少12个地产。pointStops最多16个唯一有效ID；eventPool为1—13个唯一的现有稳定事件ID，不能编写事件代码或自定义经济效果。startingCash整数1000—20000；victory为{rounds:20|30|50|80,type:ranking|netWorth,target:0或1000—100000}，复用现有模式配置与结算，不复制引擎。每局固化完整地图，名字相同的文件不改变既有存档。
JSON最大128KiB、深度最大12、节点数有界，拒绝未知键、非法类型、非有限/非整数数值、重复ID及非法引用。读取文件前检查size；编辑草稿可临时不合法，但试玩/导出必须完整通过校验。JSON Schema描述结构，图算法执行连通和汇合校验。
## 兼容与试玩
schemaVersion0旧文件使用startingMoney，迁移到v1 startingCash；未来版本拒绝，原文件不删除。旧单机mapVersion1/2仍指向原内置图，不往旧状态添加地图字段，保持确定性哈希。自定义局mapVersion3内嵌customMap，恢复时再次校验；地图名与内容均不作为身份或竞技证明。
编辑器复制模板、添加/编辑格子、编辑next连接和声明汇合点，实时绘制2D路径、编号与错误；所有用户内容按数据呈现。可导出JSON，支持时调用系统文件分享，否则下载文件后自行发送。
试玩复用完整单机UI、规则、AI和存档，但本机repository键使用专用试玩前缀，不覆盖原自动槽或手动槽；可从试玩设置导出完整对局。普通导入自定义对局也可运行；自定义地图明确只显示2D，不把自定义坐标套入固定3D地形。联机房间暂不接收自定义地图，云端单机备份只作为普通可修改进度。
## 验证
保存原内置图100步六人AI命令的状态哈希作迁移基线；测试恶意体积/深度/脚本键/文本、引用、唯一ID、环路、起点、分岔汇合、数字、旧版本、存档与确定性完整对局。浏览器实际导入、编辑连线、预览、导出、试玩，验证原存档未覆盖。
