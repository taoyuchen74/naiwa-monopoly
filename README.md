# 奶蛙大富翁

以奶家角色为主角的轻量3D单机经营小游戏，支持手机横竖屏、2—6人（1名真人＋电脑）、本机存档与离线游玩。非官方粉丝作品，玩法参考历代《大富翁》，地图、模型、界面与技能为本项目原创实现。

- [手机直接试玩 · GitHub Pages](https://taoyuchen74.github.io/naiwa-monopoly/)
- [备用试玩入口](https://naiwa-monopoly-island.chicreed128.chatgpt.site/)
- [下载离线单文件](play/奶蛙大富翁.html?raw=1)：下载后用浏览器打开，内嵌字体、音乐代码和模型，无需连接外部资源。

## 当前内容

六名角色：奶蛙、奶虫、奶鼠、奶狗、奶蛋、奶茶。奶茶按农庄参考视频重建为金色杯身、杯把、深色手套、短腿及可见茶面，原豆奶存档自动迁移到奶茶并保留资产与天赋进度。

开局可直接切换奶家滨河镇与经典发财岛，背景预览与实际路线同步；继续存档按钮单独标明存档地图。高级设置可指定或随机电脑角色、逐席设置强度、初始资金和点券、先手、种子与轮数。

购买空地后可选住宅、连锁便利店、旅馆、购物中心、加油站、研究所、公园，具有独立外观、等级上限及经营效果。还有股票成本与盈亏、银行、卡包、交通工具、神灵事件、建设拆除动画、角色技能及电脑策略。

## 本地运行

直接静态运行，无需先打包：

```sh
python -m http.server 4173 --directory dist
```

用浏览器打开 http://localhost:4173/ 。也可使用 `npm run dev`。

开发检查与生成离线包：

```sh
npm ci
npm test
npm run build
```

离线包输出到 `artifacts/奶蛙大富翁.html`（约0.91 MB）。仓库中的 `play/奶蛙大富翁.html` 是已验证成品副本。优化网页输出到 `out/`，运行 `npm run preview` 可预览；正式部署使用 `out/` 的全部文件。`dist/` 保留可直接运行和修改的模块源码。

## 加载优化

正式网页把39个模块合并成1个带内容指纹的脚本，脚本从约2.24 MB减至约762 KB（gzip约216 KB）；界面字体由约1.51 MB精简成约93 KB WOFF2。离线单文件由2.72 MB降至0.91 MB。发布文件名随内容自动变化，离线缓存按站点路径分开，断网仍可恢复已保存对局。

`npm run build` 同时生成离线包和优化网页；`out/` 为生成目录，不提交到源码分支。需要新增使用原字体的文字时，安装 `fonttools brotli` 后运行 `python tools/subset-font.py` 更新已提交的网页字体。原始字体和OFL许可保留，未覆盖字符仍按浏览器字体回退。详见 [加载验证](docs/LOADING-2026-10-24.md)。

## 持续迭代

GitHub Pages 已开启，`gh-pages` 分支根目录为从 `out/` 生成的可直接发布游戏。分享面板使用当前游玩站点；本地与离线文件分享正式 Pages 地址。修复工程队、奶蛋首次免费盖房未记录类型的问题，避免住宅收费却显示成其他设施。

## 本轮修复与验证

结算页新增冠军角色、奖杯、胜负差距和可展开的资产构成。相同净资产且存活状态一致的角色并列排名，结算存档可以导出并回看。见 [结算验证](docs/SETTLEMENT-2026-10-24.md)。


卡包新增重复卡片堆叠、数量与可用状态提示，提前说明重复效果、使用时机、目标与现金限制。路障选位禁用已有障碍和角色停靠位置。见 [卡包验证](docs/CARDS-2026-10-24.md)。


地产与建设详情现在分开展示住宿天数、商场消费范围、加油站实际步数计费、连锁店数量及研究进度；小地图补充业主与设施名称。修复路障截停后加油站仍按掷骰总数收费、公园在业主休养时不发点券的问题。实际移动计数随存档保存，岔路预览包含已行走距离。


地图保存后原先只更新摘要，背景与固定说明仍显示默认滨河镇。现已同步菜单地图实例、说明和3D重建，正式开局双向切图已在浏览器验证；旧存档保留原路线。新增直接选地图入口、存档地图提示，修正各类建筑拆除材料回收的确认金额。

145项检查覆盖引擎、股票、AI、地图、天赋、音频、动画、地图切换与旧角色迁移，含48局4/6人混合难度随机阵容模拟。手机视口检查属于桌面浏览器模拟，不声称测试过真实安卓设备。视频源模型未提取，原创轻量模型与影片渲染仍有差距。
