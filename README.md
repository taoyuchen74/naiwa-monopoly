# 奶蛙大富翁

以奶家角色为主角的浏览器3D单机经营游戏，支持手机横竖屏、2—6席（每席可选真人或电脑）、本机存档与离线游玩。非官方粉丝作品，玩法参考历代《大富翁》，地图、模型、界面和技能由本项目实现。

- [直接试玩 · GitHub Pages](https://taoyuchen74.github.io/naiwa-monopoly/)
- [备用试玩入口](https://naiwa-monopoly-island.chicreed128.chatgpt.site/)
- [下载离线单文件](play/奶蛙大富翁.html?raw=1)：用浏览器打开，无需外部素材服务。

## 自适应画质

默认采用自适应画质：桌面阴影为2048、GTAO为16样本；粗指针移动设备阴影为1024、GTAO为8样本及半尺寸，pixelRatio上限1.25。保留环境反射、物理材质、辉光和抗锯齿；省电画质关闭阴影与后处理。道路、草地、铺装、瓦片有细节纹理，水面有动态波纹。菜单和无动画静止场景按需绘制，页面隐藏时暂停。

界面使用实际3D模型渲染的头像。奶蛙、奶鼠提高曲面采样，增加捧腹手腕、躯干前倾和口腔凹陷；奶狗也补充口腔形状。可在游戏设置或地图右侧切换自适应/省电画质。

![建筑发展后的桌面浏览器画面（历史测试存档）](docs/images/cinematic-town.png)

历史实现见 [电影画质记录](docs/CINEMATIC-2026-10-25.md)，当前预算与可重复基准见 [性能报告](docs/PERFORMANCE.md)。画面以当前设备的显卡和浏览器输出为准。

## 游戏内容

六名角色：奶蛙、奶虫、奶鼠、奶狗、奶蛋、奶茶，各有可关闭的专属天赋。奶茶采用杯身、杯把、茶面、手套及短腿造型；旧豆奶存档自动迁移并保留资产。

奶家滨河镇与经典发财岛可在开局切换。高级设置可指定或随机电脑角色、逐席选择难度、统一起始资金和点券、设置先手、种子及轮数。手机开局按钮固定可见，手动旋转不依赖系统横屏锁定。

空地可建设住宅、连锁便利店、旅馆、购物中心、加油站、研究所、公园，具有独立外观和规则。还有股票成本及盈亏、银行、卡包、交通工具、神灵事件、建设拆除动画与电脑策略。结算展示冠军、并列排名及资产分项。

规则操作已接入统一命令层，包含玩家/阶段校验、递增版本、逐玩家去重及稳定状态哈希；接口与迁移清单见 [命令层说明](docs/COMMANDS.md)。当前仍为本机单机，没有服务器或网络联机。

现有12种手牌和13个随机事件。新增事件护盾、合法换位、三回合租金保险，以及股票分红、经营节和设施巡检；规则顺序、AI策略、迁移与批量模拟结果见 [内容与平衡报告](docs/CONTENT-BALANCE.md)。

支持同设备热座、单人＋AI和纯AI旁观。在席位设置中独立选择类型、角色和难度；热座真人接手前必须确认，随后才开放自己的手牌与账户。换手状态可存取档，规则、隐私边界与多人回归见 [热座说明](docs/HOTSEAT.md)。

## 本地运行

```sh
npm ci
npm run typecheck
npm test
npm run build
```

`npm run dev` 启动模块源码预览；`npm run preview` 启动编译版预览，地址均为 http://localhost:4173/ 。

构建输出为 `out/` 完整网页和 `artifacts/奶蛙大富翁.html` 离线文件。发布使用 `out/` 全部内容；GitHub的 `gh-pages` 分支为网页成品，`main` 保留源码与 `play/` 离线成品。

运行时模块合并为一个带内容指纹的脚本；当前模块数、下载体积、gzip及字体尺寸以构建生成的 `out/build-info.json` 为准。几何与纹理在运行时生成，下载体积不代表显存占用。新增界面文字后运行 `python tools/subset-font.py` 更新字体子集；字体工具需要 `fonttools brotli`。

状态、命令及存档类型采用JSDoc和独立声明渐进检查；经济结算、UI推进和迁移模块的职责及修复清单见 [类型与模块说明](docs/TYPES-AND-MODULES.md)。类型检查不生成运行时代码。

## 验证与边界

单元测试覆盖规则、股票、AI难度、完整对局、地图、天赋、音频、动画、存档、发布缓存和渲染资源生命周期；实时数量以 `npm test` 输出为准。轻量 Playwright 套件在390×844、844×390两个视口覆盖开局→掷骰→买地→建设→结束回合、音频失败无声启动、旧存档覆盖确认与备份恢复、键盘焦点隔离、WebGL失败简洁地图。

```sh
npx playwright install chromium
npm run test:browser
```

浏览器用例使用独立上下文、固定种子和时间、减少动态效果，通过真实点击、键盘和存档状态验证。轻量CI主动使用程序已有的简洁地图，避免软件绘图干扰；支持GPU的环境可用 `npm run test:browser:3d` 检查同一套流程的真实WebGL路径。CI在推送main及PR时运行单元测试、轻量浏览器测试与构建，上传HTML报告及失败截图、trace和测试存档。更广的移动端、无障碍与渲染生命周期检查分别运行 `npm run test:mobile`、`npm run test:a11y`、`npm run test:performance`；操作说明见 [浏览器QA](docs/BROWSER-QA.md)。

这些是桌面Chromium及移动视口仿真结果，不代表完成真实安卓、iOS、系统软键盘或移动GPU验证。

本版为游客单机，每个浏览器提供3个手动槽和1个自动槽，显示地图、轮数、人数、更新时间与旅行摘要。支持逐槽保存、读取、覆盖/删除确认及JSON导入导出；替换自动槽前保留独立备份。旧存档读取兼容，格式与迁移策略见 [存档说明](docs/SAVE-FORMAT.md)。账号、云存档和联机尚未实现。角色仍是原创重建，不宣称已取得参考视频的源模型或逐帧复刻。
